## Section 1: Why people search for a PassKit alternative

### H2
Why WordPress site owners look beyond PassKit

[PassKit](https://passkit.com/) is a mature platform for creating and distributing digital wallet passes at scale. Enterprise teams, airlines, and large loyalty programs use it successfully.

But if you run a **WordPress membership site**, PassKit’s default path looks like this:

1. Create passes in the PassKit portal  
2. Generate API credentials in Developer Tools  
3. Connect WordPress to PassKit via **Zapier**, **Make**, or a **custom webhook plugin**  
4. Map MemberPress or WooCommerce fields in the automation tool  
5. Pay for PassKit usage **plus** automation platform fees  
6. Debug when a Zap misfires and a member never gets their pass  

That works — but it is not a WordPress-native experience. It is infrastructure glue.

**EpassCard** was built for the opposite workflow: install a plugin, map templates, and let WordPress handle the rest.

## Section 5: Migration from PassKit

### H2
Switching from PassKit + Zapier to EpassCard

You do not need to migrate existing passes in PassKit. Most WordPress sites start fresh:

1. **Create templates** in EpassCard (similar workflow to PassKit portal).  
2. **Install EpassCard** and disable the Zapier/Make automation for new signups.  
3. **Map** each MemberPress product or WooCommerce subscription to a template.  
4. **Test** with a staging member account.  
5. **Go live** — new members receive EpassCard passes automatically.  

Existing PassKit passes on members’ phones continue to work until they expire or are removed. New members get EpassCard passes.

**Tip:** Run both systems in parallel for one billing cycle if you have active PassKit passes you cannot re-issue.

## Section 6: Setup walkthrough

### H2
How to set up EpassCard on WordPress (PassKit alternative)

1. Sign up at [app.epasscard.com](https://app.epasscard.com).  
2. Create at least one pass template (logo, colors, fields).  
3. Install [EpassCard from WordPress.org](https://wordpress.org/plugins/epasscard/).  
4. Go to **EpassCard → Connection** — paste API key or sign in.  
5. Enable **MemberPress**, **WooCommerce Subscriptions**, or **UMP** on the Connection page.  
6. Open the integration menu → **Pass Template mapping** → map fields for each plan.  
7. Subscribe as a test member → confirm pass link in admin and member account.  

**No Zapier. No PassKit API keys in WordPress. No webhook debugging.**
