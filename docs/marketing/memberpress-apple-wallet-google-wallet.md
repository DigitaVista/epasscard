## How it works

### H2
How to add a membership card to Apple Wallet on WordPress (with MemberPress)

**Setup takes about 15 minutes.** No code required.

1. **Create a pass template** in your [EpassCard account](https://app.epasscard.com) — add your logo, colors, and fields.
2. **Install EpassCard** on WordPress and connect your API key under **EpassCard → Connection**.
3. **Enable the MemberPress module** on the Connection page and save.
4. **Map each membership product** under **EpassCard → MemberPress** — choose a template and map fields (name, email, expiry, plan title, etc.).
5. **Done.** When a member completes signup, EpassCard creates their wallet pass and can email the add-to-wallet link automatically.

Members tap the link on iPhone → **Add to Apple Wallet**. On Android → **Save to Google Wallet**.

### H3
What happens after signup

- EpassCard calls the EpassCard API with mapped member data.
- A unique pass link is stored in WordPress and shown in your admin **Issued passes** list.
- The member can access the pass from the **Wallet Passes** tab in their MemberPress account.
- If enabled, they also receive the pass link by email.
- When membership data changes, the pass can update automatically.

## FAQ

### H2
Frequently asked questions

**Does MemberPress have a built-in Apple Wallet integration?**  
No. MemberPress does not ship a native wallet pass feature. EpassCard is a dedicated WordPress plugin that adds Apple Wallet and Google Wallet passes to MemberPress memberships.

**Do members need to install an app?**  
No. Members add the pass through a link — standard Apple Wallet or Google Wallet flow. No app download.

**Which phones are supported?**  
Apple Wallet on iPhone, iPad, and Apple Watch. Google Wallet on Android devices.

**Can I use different pass designs per membership level?**  
Yes. Map each MemberPress membership product to its own EpassCard template.

**Are passes updated when a member renews?**  
Yes. EpassCard issues on renewal and can update passes when mapped fields change.

**Can I manually create or resend a pass?**  
Yes. From the MemberPress members list or **Issued passes** table: **Create pass**, **Update pass**, or **Email pass link**.

**Does this work with MemberPress trials and expiring memberships?**  
Yes. Push reminder rules align with MemberPress reminder timing (subscription expire, renewal, trial, card expire). Customize title and message per reminder type.

**Is EpassCard a PassKit alternative?**  
Yes — specifically for WordPress and MemberPress sites. [Read the full comparison](/passkit-alternative-wordpress/).

**What data is sent to EpassCard?**  
Only the membership fields you map (e.g. name, email, expiry). See [EpassCard privacy policy](https://epasscard.com/).
