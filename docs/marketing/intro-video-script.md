# EpassCard intro video — plan & script

Screen-record briefing for an **intro / product walkthrough** video aimed at all EpassCard audiences: **MemberPress**, **WooCommerce Subscriptions**, and **Ultimate Membership Pro**.

**Goal:** Show a WordPress site owner: install → connect → map → member gets an Apple/Google Wallet pass.

**Tone:** Clear product demo for membership/subscription site owners. Narrate outcomes, not every UI label.

**Core message:** Same 5 steps for every platform — **Connect → Enable → Map → Issue → Wallet**.

---

## Video variants

| Variant | Length | Use for |
|---------|--------|---------|
| Full intro | ~4:00–4:10 | YouTube, website embed, onboarding email |
| Trailer | ~90 seconds | Social, WordPress.org / marketplace, ads |

**Primary demo stack:** Record a deep dive on **one** live integration (whichever is easiest on staging). Use short cuts or screenshots of the other two admin pages so every audience sees “their” menu.

## Full intro — narration script

### 1. Hook (0:00–0:20)

**Show:** Close-up of phone unlocking → Wallet → membership pass.

> “Your members already live on their phones. With EpassCard, their membership isn’t a PDF or a login page — it’s a real Apple Wallet or Google Wallet pass that updates when they renew.”

### 2. Who it’s for (0:20–0:40)

**Show:** Slide or overlay with all three logos.

> “If you run **MemberPress**, **WooCommerce Subscriptions**, or **Ultimate Membership Pro**, EpassCard connects your WordPress site to wallet passes — automatically. One plugin. Three integrations. Same simple workflow.”

### 3. Install (0:40–0:55)

**Show:** Plugins → Activate → Welcome (skip/subscribe briefly) → setup.

> “Install EpassCard, activate it, and you’ll land on the welcome screen. Subscribe for updates or skip — then continue to setup.”

### 4. Connect (0:55–1:25)

**Show:** Connection page → API key or email/password → Connected.

> “Everything starts on **EpassCard → Connection**. Create an account at app.epasscard.com, build your pass template there, then connect with an API key — or sign in with email and password to generate one. One connection powers every integration on your site.”

### 5. Enable your stack (1:25–1:45)

**Show:** Integrations table listing all three; enable the demo site’s installed module.

**On-screen text:** Enable only what you use.

> “On the same page, choose the platforms you use. Enable MemberPress, WooCommerce Subscriptions, Ultimate Membership Pro — or any mix you have installed. Save integrations, and each one appears under the EpassCard menu.”

### 6. Map once — deep demo (1:45–2:30)

**Show:** Prepared integration → Set up mapping → template → map fields → Save.

**On-screen text:** Plans · Products · Levels — same mapper.

> “Open your integration. For each membership plan, subscription product, or membership level, set up mapping. Pick a pass template from your EpassCard account. Map member name, email, plan, expiration — whatever your template needs — then save. That mapping is what turns a signup into a wallet pass.”

### 7. Same flow, other platforms (2:30–2:45)

**Show:** Quick cuts — MemberPress page → WooCommerce Subscriptions page → Ultimate Membership Pro page.

> “MemberPress maps membership products. WooCommerce Subscriptions maps subscription products. Ultimate Membership Pro maps membership levels. Same idea in every menu: map the template, save, and EpassCard takes it from there.”

### 8. Issue & deliver (2:45–3:15)

**Show:** Auto issue or Create pass → Issued passes → email toggle / My Account → Wallet passes.

> “When someone subscribes or their membership activates, EpassCard creates the pass and stores the link. You can also create or update passes from your members or subscriptions list. Turn on auto-email for the pass link, include it in WooCommerce order emails, or let members open **Wallet passes** in My Account — MemberPress account pages work the same way.”

### 9. On the phone (3:15–3:35)

**Show:** Pass link → Add to Apple Wallet / Google Wallet.

> “Your member taps the link, adds the pass to Apple Wallet or Google Wallet, and they’re done. No app from you. No special training.”

### 10. Reminders & control (3:35–3:55)

**Show:** Push notification settings + Issued passes search.

> “You can send wallet push reminders around renewals and expiry, customize the email copy, and search every issued pass from WordPress. Passes update when membership data changes — so the card in their wallet stays current.”

### 11. CTA (3:55–4:10)

**Show:** Logo + three integrations + app.epasscard.com.

> “Whether you sell with MemberPress, WooCommerce Subscriptions, or Ultimate Membership Pro — set up your template at app.epasscard.com, connect EpassCard, map once, and start issuing digital membership cards today. Links and docs are in the description.”

## Recording & edit tips

1. **Name all three early** — don’t make one audience feel like a secondary use case.
2. **Deep-dive one mapper** — then show the other two as “same flow.”
3. **Show the phone twice** — opening hook and closing add-to-wallet.
4. **Hide secrets** — blur API keys and emails.
5. **Captions** for Connect · Enable · Map · Issue · Wallet on key cuts.
6. **Don’t read every label** — say “map name and expiry” while clicking.
