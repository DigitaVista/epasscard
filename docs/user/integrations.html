Integrations

Built-in modules share one workflow: map template → issue pass → sync on changes.

MemberPress

EpassCard → MemberPress
  • Maps membership products to templates
  • Members list pass actions
  • Account Wallet Passes tab
  • 4 push reminder types

Paid Memberships Pro

EpassCard → Paid Memberships Pro
  • Maps membership levels
  • Sync on assign / checkout
  • Status-based revoke rules
  • Push: before level expires (daily cron)

Simple Membership

EpassCard → Simple Membership
  • Maps membership levels
  • Sync on register / level / status change
  • Account-state pass behavior
  • Push: before membership expires (daily cron)

The Events Calendar

EpassCard → The Events Calendar
  • Maps events to templates
  • Issues for Event Tickets (add-on) attendees
  • Attendees list Create / Update / View pass
  • Venue / organizer source fields
  • Push: before event starts (daily cron)

Events Manager

EpassCard → Events Manager
  • Maps events to templates
  • Sync on booking add / status change
  • Bookings list Create / Update pass actions
  • Push: before event starts (daily cron)

PW Gift Cards

EpassCard → PW Gift Cards
  • Maps gift card products
  • Sync on create / balance change
  • Revoke on deactivate / expire
  • Push: before card expires (daily cron)

YITH Gift Cards

EpassCard → YITH Gift Cards
  • Maps gift card products
  • Sync on generation / balance update
  • Revoke on disable / dismiss / trash
  • Push: before card expires (daily cron)

WooCommerce Subscriptions

EpassCard → WooCommerce Subscriptions
  • Per-subscription passes
  • My Account Wallet passes
  • Order email pass links
  • Renewal, trial, end reminders

Ultimate Membership Pro

EpassCard → Ultimate Membership Pro
  • Maps membership levels
  • Per ihc_user_levels record
  • Users list pass actions
  • Push: before level expires (daily cron)

Enabling / disabling

Toggle modules on the Connection page. Disabled modules do not load hooks or admin menus.

Per-module features

  • Pass Template mapping — Required before issuing passes
  • Issued passes — Search, filter, manual actions
  • Push rules — Custom title/message per reminder
  • Test notification — Verify pushes before go-live
