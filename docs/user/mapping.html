Pass Template mapping

Connect each plan or product to an EpassCard pass template and define how WordPress data fills each field.

Open the mapping UI

  1. Go to an integration page (e.g. EpassCard → MemberPress).
  2. Click Set up mapping or Edit mapping for a plan.

Steps in the modal

  1. Select template — From your EpassCard account. Refresh if you added new templates.
  2. Map fields — Source field pulls live data; Custom value sets fixed text.
  3. Save mapping — Stored per entity id in WordPress options.

Source fields

Typical options: member name, email, status, start/expiry dates, product title. Developers can add more via epc_mapping_source_fields — see Mapping extensions.

Tips

Map all required template fields. Use custom values for static labels (venue, brand). Re-open mapping after editing templates in EpassCard.
