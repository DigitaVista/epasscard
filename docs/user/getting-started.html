Getting started

Install EpassCard, connect to your account, and start issuing wallet passes for memberships, events, and gift cards.

Requirements

  • WordPress 6.5+
  • PHP 8.1+
  • An EpassCard account with at least one pass template
  • At least one supported plugin:
    • Membership: MemberPress, Paid Memberships Pro, Simple Membership, Ultimate Membership Pro
    • Subscriptions: WooCommerce Subscriptions
    • Events: The Events Calendar (with Event Tickets add-on), Events Manager
    • Gift cards: PW WooCommerce Gift Cards, YITH WooCommerce Gift Cards

Installation

  1. Upload the epasscard folder to wp-content/plugins/.
  2. Activate EpassCard under Plugins.
  3. Open EpassCard → Connection in the WordPress admin.

Basic setup

  1. Connect — Paste your API key or sign in with EpassCard credentials.
  2. Enable integrations — Check the plugins you use and save.
  3. Open an integration — e.g. EpassCard → MemberPress or EpassCard → The Events Calendar.
  4. Map templates — Choose a pass template and map fields per product, level, ticket, event, or gift card.
  5. Issue passes — Automatic on subscribe / booking / gift card issue, or manual via Create pass.
Smartest card solution

Like EpassCard itself, this plugin bridges your brand and customers with dynamic digital passes for Apple and Google Wallet — no plastic required.

What happens after setup

  • Qualifying records get a wallet pass via the API; the link is stored locally.
  • Status changes can update or revoke existing passes (per integration).
  • Optional reminder pushes use native timing (MemberPress, WCS) or EpassCard’s daily cron (other modules).
  • Pass links can be emailed, included in order emails, or viewed in My Account where supported.

Getting help

  • Help in the EpassCard top bar lists the tutorials and guides.
  • Chat with us (next to Help) opens a chat with EpassCard support: green dot during support hours (10:00–19:00 Bangladesh time, Saturday to Thursday), otherwise leave a message and we reply by email.
  • Nothing is loaded or sent until you start a chat; the panel shows what is sent (never the API key or your customers' data). Hide the button for yourself under Settings → Advanced, or for the whole site with the epc_support_chat_enabled filter.
